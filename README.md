# Neural-Network-From-Scratch

Neural Network From Scratch for Data Science & Analytics
(No Machine Learning Frameworks)

 Project Overview
This project demonstrates a full end-to-end machine learning pipeline built completely from scratch, without using any deep learning or machine learning frameworks such as TensorFlow, PyTorch, or scikit-learn.
The goal of this project was to deeply understand how neural networks actually work under the hood, including:
Loss functions
Partial derivatives
Backpropagation
Gradient-based optimization
In addition to the modeling aspect, the project also emphasizes data analytics, visualization, and business-level insights, making it suitable for Data Analyst, Data Scientist, and Machine Learning roles.

Project Architecture
The project follows a clean, production-style workflow:
Data Generation – Simulated realistic business data
Exploratory Data Analysis (EDA) – Statistical summaries & visual inspection
Feature Engineering & Scaling
Neural Network Design
Multiple hidden layers
ReLU activation
Loss Function
Mean Squared Error (MSE)
Optimization
Gradient Descent (manual backpropagation)
Model Evaluation
RMSE
R² Score
Visualization & Interpretation

Future Enhancements
Adam optimizer implementation from scratch
Gradient checking for numerical validation
Classification neural network variant
Regularization & overfitting analysis
Conversion to modular multi-file architecture
